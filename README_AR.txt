تطبيق مركز نوره للصيانة - مشروع Android WebView

طريقة إنشاء APK دون تثبيت Android Studio:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub لديك، مع إظهار المجلدات المخفية مثل .github.
2) افتح المستودع في GitHub ثم تبويب Actions.
3) اختر Build Noura Workshop APK ثم Run workflow (أو انتظر اكتمال البناء بعد رفع الملفات).
4) بعد نجاح البناء افتح تشغيل workflow الناجح وانزل إلى Artifacts.
5) نزّل NouraWorkshop-debug-apk.zip وفك الضغط لتحصل على app-debug.apk.
6) انقل APK إلى هاتف Android وافتحه. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

ملاحظات:
- هذه نسخة Debug للتجربة والتثبيت اليدوي، وليست نسخة متجر موقعة للنشر.
- البيانات محفوظة محليًا داخل WebView على الجهاز؛ استخدم النسخ الاحتياطي عند الحاجة ولا تمسح بيانات التطبيق أو تخزينه.
- يلزم اتصال بالإنترنت فقط لرفع المشروع وبناء APK على GitHub؛ التطبيق نفسه يحمل HTML محليًا.
- الطباعة تستخدم نافذة الطباعة الأصلية في Android، وقد يختلف شكل الإخراج حسب إصدار الجهاز والطابعة.
- لم يتم تشغيل التطبيق على جهاز Android فعلي هنا. افحصه بعد التثبيت قبل استخدامه للبيانات الفعلية.
